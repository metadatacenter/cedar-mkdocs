# CEDAR REST APIs

CEDAR exposes repository operations through REST APIs. The resource API covers search, validation,
content negotiation, and permission-aware CRUD for templates, elements, fields, instances, folders,
and categories. It also exposes artifact versioning and sharing operations.

Start with [Authentication](authentication.md) and [Working With Artifacts](working-with-artifacts.md).
[Resource Changes and API Conventions](resource-changes.md) describes partial updates, identifiers,
and the current terminology parameter names. [ETag Concurrency](etag-concurrency.md) and
[Paging](paging.md) cover the contracts shared by these operations. The
[interactive reference](interactive-api.md) describes each deployment's exact API.
