# CEDAR Permission Model

CEDAR supports collaboration. A CEDAR user can work individually or as part of a group—a
named collection of users. Users organize metadata resources in folders, work on them together,
and can make them available outside CEDAR. The permission model provides a
consistent way to decide who can see, change and control each resource.

This document specifies the permission model that CEDAR is intended to provide. Its rules define the
expected behavior and provide a basis for determining whether an implementation conforms to the
model.

Together, these rules are intended to support collaboration without making ownership, re-sharing or
public access ambiguous.

Artifact versioning and publication are separate lifecycle concerns. Authentication, deployment
roles and service credentials are also outside this document.
