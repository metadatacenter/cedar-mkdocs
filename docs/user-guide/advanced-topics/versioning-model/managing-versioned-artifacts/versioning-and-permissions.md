# Versioning and Permissions

Collaborators with [**Editor**](../../permission-model/roles-and-grants.md) access can help edit a draft,
but its owner decides when to publish it.
Only the owner of the latest published version can create the next draft. That owner must also have
**Editor** access to the destination folder. The [**Manager**](../../permission-model/roles-and-grants.md)
role alone does not grant these
versioning actions.

Each version has its own owner, folder and sharing settings. When creating a draft, the owner can
copy the published version's sharing settings. The draft also inherits access from its destination
folder. Later changes to one version's direct sharing settings do not change the settings on other
versions.

Transferring ownership gives the new owner responsibility for publishing that draft or creating the
next version from that release. The same lifecycle rules still apply. Other versions keep their
owners. The [permission model](../../permission-model/index.md) defines the full access rules.
