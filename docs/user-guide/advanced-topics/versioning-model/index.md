# CEDAR Versioning Model

Templates, elements and fields evolve as metadata requirements change. CEDAR versioning lets authors
develop new versions while keeping earlier published definitions available for continued use.

Authors work on an editable draft and publish it when it is ready for use. Publication fixes the
content of that version. To make further changes, the author creates a new draft from the latest
published version. This allows development to continue without changing the definition that others
already use.

The model follows the Maven distinction between a mutable development version and a fixed release.
CEDAR records draft status separately from the version number.
